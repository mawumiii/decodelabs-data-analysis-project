# Decodelabs Sales Data Analysis Project

## 📌 Project Overview

This is my first data analytics project completed during my Decodelabs internship.

The main goal of this project was to clean, prepare, and analyse a raw sales dataset to identify meaningful trends and patterns. Data cleaning is an important step in the data analytics process because the quality of the data directly affects the quality of the insights obtained from it.

## 🎯 Project Objectives

### Week 1 — Data Cleaning and Preparation

The project focused on:

* Understanding the structure of the dataset
* Identifying missing values
* Checking for duplicate records
* Identifying and handling data inconsistencies
* Correcting data types where necessary
* Removing or addressing unnecessary data
* Producing a clean dataset ready for analysis

### Week 2 — Exploratory Data Analysis and Trend Identification

The second week focused on exploring the cleaned dataset to identify trends, patterns, and relationships within the sales data.

The objectives were to:

* Explore the cleaned dataset using Python and Pandas
* Analyse sales performance over time
* Identify yearly and monthly sales trends from 2023–2025
* Identify recurring or seasonal sales patterns
* Compare sales performance across different periods
* Analyse product performance
* Identify high and low-performing products or periods
* Detect unusual values and potential outliers
* Use data visualizations to communicate findings
* Generate meaningful business insights from the analysis

## 🛠️ Tools Used

## 🔎 Data Cleaning Process

The following steps were performed during Week 1:

1. Loaded the dataset into Python using Pandas.
2. Inspected the dataset structure and columns.
3. Checked for missing values.
4. Identified duplicate records.
5. Reviewed data types and corrected them where necessary.
6. Checked for inconsistencies and unusual values.
7. Cleaned the dataset based on the identified issues.
8. Exported the cleaned dataset for further analysis.

## 📊 Exploratory Data Analysis

During Week 2, the cleaned dataset was analysed to understand sales performance and identify meaningful patterns.

The analysis included:

* Yearly sales analysis
* Monthly sales analysis
* Product performance analysis
* Trend analysis
* Pattern and seasonality analysis
* Outlier identification
* Data visualization
